# Bloat DJ — Releases

Instaladores e versões portáteis do **Bloat DJ** (app de DJ para Windows).

- **BloatDJ-x.y.z-Setup.exe**: instala e se atualiza pelo botão *Procurar atualizações* (CONFIG. > Geral).
- **BloatDJ-x.y.z-win64-portable.zip**: versão portátil (descompacte e rode `Bloat DJ.exe`).

Baixe a versão mais recente em [Releases](https://github.com/frikkek/Bloat-DJ-Releases/releases/latest).

Os pacotes não contêm configurações, biblioteca nem cache de nenhum usuário.
